# ggswim arrow defaults

ggswim arrow defaults

## Usage

``` r
.default_arrow_colours

.default_arrow_fills

.default_arrow_types

.default_arrow_limits
```

## Value

Character vectors giving the default arrow outline colour (`"black"`),
fill (`"black"`), head type (`"closed"`), and category limit
(`"Continuation"`). Each vector contains one value.

## Examples

``` r
ggswim::.default_arrow_colours
#> [1] "black"
ggswim::.default_arrow_fills
#> [1] "black"
ggswim::.default_arrow_types
#> [1] "closed"
ggswim::.default_arrow_limits
#> [1] "Continuation"
```
